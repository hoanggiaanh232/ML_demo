📱 Shortcode Usage

Use these shortcodes in your WordPress posts or pages:

[meta_broadcast_icon]

Default: Fixed position, blue color (#1877f2)

[meta_broadcast_icon position="relative" color="#ff6b6b"]

Custom: Relative position, red color

[meta_broadcast_icon color="#28a745"]

Fixed position with green color

✨ Key Features

🎯 Smart Badge

Shows unread count with pulsing animation. Updates in real-time every 30 seconds.

🎨 Customizable Design

Change icon color and position to match your site's branding.

📱 Mobile Responsive

Optimized for all screen sizes with touch-friendly interactions.

🌙 Dark Mode Support

Automatically adapts to user's system preference for dark/light mode.

⚡ Auto Mark Read

Notifications are automatically marked as read when the popup is opened.

🔒 User-Specific

Each user sees only their unread notifications with proper tracking.

🔧 Admin Panel

The plugin includes a complete admin interface for managing broadcasts:

  • ✅ Create new broadcasts with rich text editor
  • ✅ View all existing broadcasts in a table
  • ✅ Delete broadcasts with confirmation
  • ✅ Usage instructions and examples
  • ✅ Character counting and form validation

Admin menu location: WordPress Admin → Broadcasts
